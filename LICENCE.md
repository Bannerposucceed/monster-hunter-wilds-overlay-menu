## 🧩 About

**Monster Hunter Wilds Companion** is a curated list of Monster Hunter Wilds open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD reference, map overlay notes
- **Quality-of-Life Helpers** — loot catalog, quest board notes, overlay config notes
- **Research Notes** — hunt layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Map Overlay — reference map and zone notes on screen
- Loot Tracker — catalog gathered materials and drops
- Quest Notes — record and review hunt objectives
- HUD Layout — adjust on-screen overlay placement for study

### Wallhack
- Gear Catalog — browse armor, weapons, and talismans
- Palico Notes — organize companion cosmetics
- Material Index — reference crafting materials and locations

### Aimbot
- Route Notes — segment study across locales
- Weather Toggle Notes — reference climate and hazard states
- Stamina Reference — track gauge behavior in the field
